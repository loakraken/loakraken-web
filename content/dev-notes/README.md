# LOAKraken 개발자 노트

이 폴더의 마크다운 파일이 소식 탭의 'LOAKraken 개발자 노트'로 보입니다.

- 파일 이름: `YYYY-MM-DD-주소.md` (주소는 영문 소문자·숫자·`-`). 예: `2026-10-19-v0-3-1.md` → `/news/dev-notes/2026-10-19-v0-3-1`
- 이 이름 모양이 아닌 파일(이 README 등)은 글로 보이지 않습니다.
- 맨 위 frontmatter:

```
---
title: 글 제목 (필수)
date: 2026-10-19 (선택, 없으면 파일 이름의 날짜)
summary: 목록과 검색 결과에 보일 한 줄 요약 (선택)
pinned: true (선택, 목록 맨 위에 '고정' 표시와 함께. 여러 개면 날짜 최신순)
---
```

- 본문에 쓸 수 있는 것: `#`·`##`·`###` 제목, 문단, `-` 목록, `1.` 번호 목록, 표(`| a | b |` + `|---|---|`), `>` 인용, `---` 구분선, `**굵게**`, `` `코드` ``, `[글자](https://…)` 또는 `[글자](/경로)` 링크.
- HTML은 글자 그대로 보이고 실행되지 않습니다.
- 공개 저장소입니다. 내부 기록·경로·일정·다른 사이트 이름은 넣지 않습니다. 화면 문구는 '유저'로 씁니다.
