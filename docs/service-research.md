# 통합 서비스 추가 조사와 제품 반영

확인일: 2026-10-04. 기존 10개에 로아랩·로아또·로아베스팅을 추가해 참고 대상을 13개로 확장했다. 로스트빌드(LostBuilds), 로펙, 로아와는 기존 대상이다. 아래에서 서비스 관찰과 LOAKraken 설계 결정을 구분한다.

## 로아랩 — 조건별 효율 비교

공식 공개 페이지에서 확인한 내용:

- [치명타 계산](https://lo4.app/tools/blunt-thorn): 캐릭터와 뭉툭한 가시, 펫·백어택·시너지 조건을 함께 설정한다.
- [음속 돌파](https://lo4.app/tools/supersonic-breakthrough): 공이속의 구성 요소를 입력하고 신속에 따른 결과를 비교한다.
- [젬 교체 효율](https://lo4.app/tools/gem-upgrades): 홈에 별도 도구로 노출되지만 상세 결과는 이번 수집에서 확인하지 못했다.
- [지옥·나락](https://lo4.app/tools/hell-reward): 보상·열쇠 가치와 진행 판단을 조건별로 나눈다. [제작 계산](https://lo4.app/tools/item-craft)은 재료 시세, 수수료, 대성공과 직접 채집 여부를 구분한다.

반영: 치적·뭉가·음돌 계산을 일반적인 빌드 시뮬레이션에 명시적으로 포함한다. 조건을 공유하는 설정 패널과 변경 전후 차이를 제공하고, 젬과 보석을 구분한다. 생활 제작·보상 효율은 거래소 관측 시점과 비용 가정에 연결한다.

제한: 직접 Edge 접속은 보안 확인 403이므로 우회하지 않았다. 위 내용은 공개 웹 본문과 링크에 근거하며 실제 계산 결과·모바일 조작·수식은 미검증이다.

## 로아또 — 화면 인식과 수동 입력

[공식 홈](https://loatto.kr/), [젬파고](https://loatto.kr/gempago), [돌파고](https://loatto.kr/dolpago), [통합 재련](https://loatto.kr/refining-simulator)을 실제 브라우저에서 확인했다.

- 젬파고는 화면 인식/수동 입력을 분리한다. 수동 입력으로 전환하자 젬 상태·남은 횟수·비용·등장 선택지와 취소/재실행 UI가 나타났다. 목표를 지정하고 선택지가 갖춰지면 추천하는 흐름이다.
- 돌파고는 목표와 감소 옵션 허용 여부·우선순위를 먼저 정한다. 이번 방문에서는 리소스 로딩 안내가 남아 실제 인식은 확인하지 못했다.
- 통합 재련은 캐릭터를 기준선으로 삼고 목표·보유 재화에 연결한다. 홈에는 일반/상급/특수 재련, 보조 재료, [지옥·나락](https://loatto.kr/hell-rewards), [싱글코인](https://loatto.kr/single-exchange), 경매 도구도 있다.

반영: 화면 인식이 실패해도 수동 편집·취소가 가능한 도우미를 별도 영역으로 둔다. 재련은 방식별 도구와 통합 견적을 연결하고 보유·귀속 재료를 차감한다. 보상 가치는 사용자가 조정할 수 있는 조건으로 취급한다.

제한: 게임 화면을 공유하지 않았다. 실제 인식 정확도·추천 수학·최종 재련 견적·저장 동작을 검증한 것은 아니다.

## 로아베스팅 — 목표 견적과 시뮬레이션

[재련 견적](https://www.loavesting.com/calculator/t4), [팔찌](https://www.loavesting.com/bracelett4), [장신구](https://www.loavesting.com/acc), [패키지](https://www.loavesting.com/package), [숙제](https://www.loavesting.com/todo)를 실제 브라우저에서 확인했다.

- 재련은 캐릭터 검색 → 목표 → 책·숨결 설정의 단계로 안내한다. 대상 장비 조건과 보유 수량·비용 합산 안내가 함께 있다.
- 팔찌의 효과 부여와 장신구 연마 버튼을 각각 한 번 실행해 옵션 및 사용 재화 표시가 변하는 것을 확인했다. 이는 웹 시뮬레이션 관찰이며 확률의 정확성 검증은 아니다.
- 패키지는 통화 종류·환산 기준을 먼저 설정한다. 방문 당시에는 패키지 목록이 비어 있었다. 숙제는 원정대 등록 전 빈 상태와 일일·주간 진행률·골드를 보여준다.

반영: 목표 견적과 랜덤 옵션 시뮬레이션을 분리한다. 비용 산정에는 보유량·단가·구매 필요량을 표시하고, 시뮬레이션에는 반복 횟수·소모 재화·초기화를 제공한다. 패키지 데이터가 없으면 효율을 추정해 채우지 않는다.

## 기존 서비스와의 연결

- [로펙](https://lopec.kr/): 캐릭터 평가·팔찌·스펙업 가이드 연결을 유지한다. 최신 공지에는 과거 딜 증가량 카드의 제거와 계산 조건 변경도 있어, 특정 시점의 UI를 영구 기준으로 삼지 않는다.
- [로아와](https://loawa.com/): 통계·랭킹을 별도 흐름으로 유지하고 직업·세팅·구간·집계 시점을 설계한다.
- [로스트빌드](https://lostbuilds.com/simul): 현재 세팅을 기준선으로 지정해 대미지·DPS·버프를 비교하는 구조를 참고한다.
- [아이스펭](https://loa.icepeng.com/): 기존 비교 자료로 유지한다. 사용자가 전달한 지인의 이용 경험만으로 서비스 종료나 전체 이용 감소를 단정하지 않는다. 재련 UX 조사는 새로 요청된 로아베스팅·로아또·로아랩을 우선한다.

공개 페이지에서 로아랩 지옥 보상은 시즌4, 로아또 해당 페이지는 시즌3로 표시됐다. 어느 계산이 더 정확한지는 확인하지 않았다. 따라서 우리 계산·추천에는 시즌·패치·관측 시각과 검증 범위를 함께 표시해야 한다.

## 화면 인식 레이드 공략 — 사용자 추가 목표

이는 위 사이트에서 확인한 기능이 아니라 사용자가 추가한 LOAKraken의 제품 목표다.

1. 사용자가 선택한 게임 화면 또는 이미지와 레이드·난이도 정보를 받는다.
2. 보스·페이즈·기믹을 인식하고 불확실한 결과는 확인·수정할 수 있게 한다.
3. 패치 기준이 확인된 공략에 연결해 현재 행동과 다음 주의사항을 짧게 안내한다.
4. 실시간 안내와 수동 선택을 제공하고 인식 중단·재연결·오인식 수정·알림 중복을 처리한다.

단계: 수동/이미지 기반 공략 연결 → 제한된 보스·기믹 인식 실험 → 정확도·지연·오인식 검증 → 실시간 안내 확장. 인식 데이터셋과 공략 근거, 안내 지연을 검증하기 전 완성 기능으로 공개하지 않는다. 전투 중 안내에서는 정보의 우선순위와 가독성을 먼저 확보한다.

## 로드맵 변경

기존 8개 영역의 성장 견적·시뮬레이션·계산기 범위를 구체화하고, 06 화면 인식 도우미를 추가해 9개 영역으로 확장했다. 기존 원정대·일정·정보 목표는 07~09로 유지한다. 연구·계획 반영이며 실제 계산기나 화면 인식 엔진 구현 완료를 의미하지 않는다.
