# 사이트 전체 체크리스트 — 일로아·로아와·로아랩 (PM 16:39 ④)

관련: [[공개 기준 체크리스트 (로펙·클로아)]](같은 형식, 공개 기준), [[일로아 기능 전수표]], [[일로아 캐릭터 화면 전수표]], [[로아와 기능 전수표]], [[로아랩 기능 전수표]], [[흡수 현황]]

## 0. 읽는 법

- **공개 기준은 로펙·클로아 100%**([[공개 기준 체크리스트 (로펙·클로아)]]). 이 표는 그 다음 대상인 세 사이트의 **사이트 전체** 기능이다. 로펙·클로아와 겹치는 기능은 같은 ID 체계가 아니므로(여기는 M번호) 겹침 열에 "로펙/클로아 L·K"를 적었다.
- 관찰 날짜: 일로아 캐릭터 화면은 **2026-10-11 오늘**(전수표 일로아 캐릭터 화면 전수표), 일로아·로아와·로아랩의 나머지 메뉴는 각 전수표의 기록(2026-10-09~10-10)을 옮겼다. 오늘 다시 열어 보지 않은 화면은 비고에 "10-09/10 기록"으로 적었다(바뀌었을 수 있음).
- 판정(크라켄, web develop `c647466` 기준): 있음 / 부분 / 없음 / 보류(PM 정책으로 흡수 안 함 또는 결정 대기).
- 담당·데이터 출처·의존은 [[공개 기준 체크리스트 (로펙·클로아)]]와 같은 뜻이다.
