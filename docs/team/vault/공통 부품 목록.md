# 공통 부품 목록

## 원칙

- **실제로 두 곳 이상 반복되는 것만** 부품으로 묶는다. 한 곳에서만 쓰는 모양은 그 화면 모듈에 둔다.
- 상태: 기본·hover·focus는 모두 만든다. disabled·오류·선택은 그런 조건이 실제로 있는 부품에만 넣는다.
- 기존 기능·문구·접근성 속성(`aria-pressed`, `aria-current`, `aria-expanded`)은 그대로 유지한다.
- 위치: `components/ui/**`. 값은 [[디자인 값 명세]]의 변수만 쓴다.
- 화면 컴포넌트가 이 부품으로 바꾸는 작업은 프론트 소유다. 부품 PR이 병합되면 프론트에 교체 대상 목록을 보낸다.

## 사용 안내 (web PR #89)

- 경로: `@/components/ui/button`(Button), `icon-button`(IconButton), `chip`(Chip), `skeleton`(Skeleton)
- Button 로딩은 `disabled`가 아니라 `loading`을 쓴다.
  - `loading`이면 포커스와 너비, 접근 이름이 유지되고 `aria-busy`가 붙는다.
  - `disabled`로 바꾸면 키보드 포커스가 사라진다(WCAG 2.4.3).
- 로딩이 끝난 결과는 결과 영역에 `aria-live="polite"`(또는 `role="status"`)를 두어 알린다. 버튼만으로는 완료가 전달되지 않는다.
- Skeleton은 `aria-hidden`이다. 감싸는 영역에 `aria-busy="true"`와 이름(예: `aria-label="불러오는 중"`)을 둔다.
- 입력·선택·스위치·Segmented는 이름이 필수다: Input·NativeSelect는 `<label htmlFor>`(보이는 라벨이 없으면 `aria-label`), Segmented는 그룹에 `aria-labelledby`/`aria-label`, Switch는 `<label>`로 감싼다(web PR #115).
- IconButton은 `aria-label`이 필수다. 아이콘에는 `aria-hidden`을 붙인다.
- DataTable 현재 행은 `aria-current="true"`로 표시한다(틴트 + 3px 막대가 자동으로 붙음). `data-current`만 쓰면 모양은 같지만 스크린리더가 모르므로 `aria-current`를 우선한다. 영역 이름 `label`은 필수다.
- 툴팁은 마우스·키보드 전용이다. 터치에서는 열리지 않으므로 꼭 필요한 정보(경매 계산식 등)는 화면 글자나 팝오버로 보인다.
- 툴팁 안에 단축키(Kbd)를 넣을 때는 모양을 다시 확인한다(#140에서 shadcn Kbd 규칙을 뺐다).
- Tooltip 내용은 스크린리더에 연결되지 않는다(Base UI가 aria-describedby를 붙이지 않음). 꼭 필요한 정보(갱신까지 남은 시간 등)는 버튼 이름이나 화면 글자로도 보인다.
- QualityBadge는 `value`만 넘기면 구간과 색이 정해진다. 화면의 `qualityTier()`는 `@/components/ui/quality-badge`의 것을 쓰면 한 곳으로 모인다.
- 등급 글자색(`text-grade-*`, web #178)은 `--secondary` 칩 위에는 쓰지 않는다(4.10~4.81로 미달). 흰·회색 띠·카드 위에서만 쓴다.
- Chip은 `pressed`/`onPressedChange`(Base UI Toggle)로 쓴다. 비활성은 흐리게 하지 않고 회색 글자로 보인다.

## 긴 텍스트 처리 규칙 (2026-10-10, PM 총괄 확인 요청에 따라 추가)

공통 부품에는 말줄임 규칙이 없었다. DataTable은 nowrap에 가로 스크롤이고, Button·Chip·Tab은 nowrap이다. 이제 다음을 따른다. 상세는 [[모션 적용 대조표]] 4절에 있다.
- **표:** 기본은 nowrap + 가로 스크롤이다. 긴 이름 칸(아이템명·길드명·칭호·효과 문장)만 최대 폭을 주고 `truncate`하며, 전체 값은 `title`이나 툴팁으로 보인다. 숫자·금액·캐릭터 이름 칸은 말줄임하지 않는다.
- **카드·목록:** 제목은 한 줄 말줄임, 설명은 `line-clamp-2`다.
- **버튼·칩·탭:** 줄바꿈과 말줄임 모두 하지 않고, 넘치면 부모가 가로 스크롤한다.
- **방식:** CSS로만 줄인다. 글자 자체를 잘라 내지 않는다.

## DataRefreshState · SkeletonValue (2026-10-12)
- `components/ui/data-refresh-state.tsx` — "마지막 갱신 N초 전 · 상태" + 갱신 버튼 한 줄. Motiq Data Refresh State(MIT)의 상태 체계를 따름(대기·갱신 중·갱신됨·오래된 값·오프라인·갱신 실패).
  ```tsx
  const q = useQuery({ ... })
  <DataRefreshState
    label="시세 갱신"
    updatedAt={q.dataUpdatedAt}
    fetching={q.isFetching}
    failed={q.isError}
    onRefresh={() => q.refetch()}
    cooldown={30_000}       // 백엔드 캐시와 같게
    staleAfter={10 * 60_000} // 이보다 오래되면 '오래된 값'
  />
  ```
  - 버튼은 갱신 중·쉬는 시간·오프라인이면 aria-disabled(포커스는 됨), 툴팁이 이유를 말함. 상태 단어만 role=status로 읽힘(초 단위 시계는 안 읽힘). 움직임은 아이콘 회전(transform)뿐, reduced-motion이면 정지.
- `components/ui/skeleton.tsx` `SkeletonValue` — 글줄 안 숫자 하나의 자리표시. 높이 1lh(주변 글꼴 그대로), 폭 `chars`ch → 값이 같은 자리에 들어와도 움직임 0(CLS 0). 숫자 카드에 `aria-busy` 함께.
  ```tsx
  <strong className={styles.value}>{data ? number(data.combatPower) : <SkeletonValue chars={8} />}</strong>
  ```


## 10-12 새벽에 병합된 부품 (2026-10-12)
- `components/ui/empty-state.tsx` `EmptyState` (#586) — 빈 칸 하나에 이유 한 문장. `reason`은 필수(이유 없는 빈 화면이 곧 결함).
  ```tsx
  <EmptyState kind="skipped" reason="시세가 없는 재료라 합계에서 뺐어요." size="row" />
  ```

  ```tsx
  <Sparkline values={item.spark7.map((d) => d.averagePrice)} label="7일 평균가 추이, 4.7% 오름" />
  ```
