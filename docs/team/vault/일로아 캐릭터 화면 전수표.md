## 11. 프론트가 바로 쓸 우선순위 (레퍼런스 의견)

1. **아바타 탭 전신 이미지**(사용자 지적): 2열 배치(왼쪽 이미지 폭 약 55%, 오른쪽 목록), 목록은 슬롯 12칸 고정(빈 칸 "-"), 카드에 귀속·거래·성향·판매불가 줄. 이미지는 전투 탭 배너와 같은 공식 프로필 이미지를 쓰면 데이터 추가가 필요 없다(백엔드 확인).
2. **스킬**: 카드에 쿨타임·마나·무력화·슈퍼아머(공식 tooltip 줄 확인), 행에 어택 방향·무력화 칩과 보석 칩(눌러 보석 카드), **전체 트포 / 활성 트포** 토글, 오른쪽 스킬 포인트·카운터·스킬 효과 카드.
3. **내실**: 종류 상세에 획득처·보유율·희귀한 순(백엔드 정적 표 + 일로아식 표본 대신 우리 관측 표본, 표본 수 표시) — 수집품 순위 카드는 [[랭킹 종류 비교]] ① 작업과 같이.
4. **아크 패시브**: 트리 전환 + 티어 격자(비활성 노드 흐리게).
5. **통계**: 칭호 기록을 통계 탭으로(요약 3칸 + 주요/일반 표).
6. 나머지(길드·사사게·원정대 요약·주간 골드·이미지 공유·특성 시트)는 배정 후.

## 12. 미관찰·한계

- 일로아의 **스킬 룬 올림 카드와 염색 표시**는 언새늘이 룬·염색을 쓰지 않아 못 봤다(룬 카드 규격은 [[작은 동작 전수표]] 2c, 다른 캐릭터 측정).
- 랭킹 카드 머리 "?" 도움말, 길드 탭의 길드명 검색 결과, 내실 "통계 ›" 이동 화면, 분석 메뉴 5개의 도착 화면은 열어 보지 않았다.
- 모바일(390)에서 탭별 모양은 이번에 보지 않았다(특성 시트가 모바일에서 아래 시트인 것은 코드 클래스로만 확인).
- 우리 화면은 코드 기준이다(위 0절).
